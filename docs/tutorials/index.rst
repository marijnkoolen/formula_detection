Tutorial series
================

A step-by-step series for historians and other domain researchers
working with historical text datasets, who have a research question but
no background in programming or data science. Each notebook is
self-contained and builds on the previous ones; start with the first one
if you're new, or jump to whichever topic answers the question you have.

The series is complete in seven parts, from "what is a formula" through to
comparing formulaic language use across historical periods.
